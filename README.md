# MathMatrix 3D — Isometric Tactical Calculator

An engineering-grade web calculator featuring a real 3D physical isometric perspective, dynamic chalkboard formula particles, and synthesizer audio feedback.

## Features
- **3D Isometric Physics:** Realistic tactile key depression states on click.
- **Mathematical Background Matrix:** Floating animated formula particle layer.
- **Synthesizer Audio Feedback:** Dynamic audio generated on-the-fly via the Web Audio API.
- **Full Arithmetic Support:** Handles positive/negative floats and integers with expression history.
